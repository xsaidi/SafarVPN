# SafarVPN for Android

Official signed APK releases of SafarVPN for Android 9 and newer.

## Download

Open [the latest release](https://github.com/xsaidi/SafarVPN/releases/latest) and download `SafarVPN-VERSION-universal-release.apk` under **Assets**.

Website and video guide: [safarvpn.ru](https://safarvpn.ru/download.html).

This repository contains release files and download information only. Application source code is maintained in a separate private repository. GitHub-generated "Source code" archives in these releases contain this download README, not the application's source code.
